以下是一份技術文件 Markdown 的所有標題行（格式：行號: 標題內容）：

{headings}

請根據技術文件的結構邏輯，判斷每個標題應該使用幾個 # 符號。

規則：
- 文件主標題用 #（一個）
- 頂層章節用 ##（兩個）：數字編號 1. 2. 3.，或無編號的主要章節（Overview、Introduction、Installation、Configuration、API Reference 等）
- 次級章節用 ###（三個）：數字編號 1.1 2.1，或功能子項目
- 三級章節用 ####（四個）：數字編號 1.1.1，或更細的子項目

只輸出 JSON，key 為行號（數字），value 為 # 數量（1-4）：
{"行號": 數量, ...}
