## 行為（對齊設計）
- filter 模型：點資料夾＝切換 currentFolderId 並 client-side filter `allPapers`，不重抓論文
  （切資料夾零 API 往返；新增/移動/刪除才 reload）
- 全部＝所有論文；未分類＝folder_id==null；某資料夾＝該 folder + 所有子孫遞迴
- 處理中論文 folder_id=null → 顯示於「全部」「未分類」（不藏，符合 G）
- 「閱讀提前」邏輯不受影響：renderPapers 沿用 data-id、`if(p.id===currentPaperId)`active；
  loadPaper / paperReadiness / trackProgress 的 `loadPapers().then()` 契約維持
  （loadPapers 仍回 promise、render 後 .paper-item[data-id] 存在）
- localStorage：`foldersOpen` 持久化展開狀態；currentFolderId 不持久化，重整回 'all'（符合 I）
- MVP 不做：拖曳、批次移動、排序拖曳、移動資料夾改 parent UI（API 已支援，UI 後續）
