## 副作用 / 疑慮（誠實標註）
1. **spec 內部衝突（修正#1 vs I4）**：修正#1 要求「新資料夾」拿掉 icon，
   但 I4 明確要求 new-folder 以 32×32 icon 置於 h1 右側。二者矛盾。
   採 **I4**（保留 folder＋ icon、icon-only 置 header 右）——理由：修正#1 之描述
   建立在 new-folder 仍於 sidebar-bottom 作文字鈕的前提，I4 是針對新位置的明確指示，
   且 48px header 右側放文字鈕過擠。已於此標註，待你裁示是否改純文字。
2. **面板收合按鈕未移入 header**：#sidebar-toggle 為 position:fixed；若移入
   #sidebar 內，當側欄 collapsed(width:0;overflow:hidden) 時該鈕會消失、無法再展開。
   故維持其 fixed（功能即「左側漢堡/收合」），未於 h1 右側再加第二顆收合鈕（會重複且破功能）。
   I4「右：新資料夾＋收合」中之收合＝既有 fixed 鈕（視覺位於 h1 左上）。已標註此取捨。
3. **舊 CSS 殘留**：.paper-move-btn / .delete-btn 規則仍在（已不被 render 使用，
   .delete-btn 仍在 ghost 群組選擇器中，無害）；未刪以縮小 diff、避免誤傷彈窗等其他用途。
4. textarea autogrow 與 SSE 無衝突（SSE 寫 #chat-messages）；多行時輸入區
   align-items:flex-end 使送出鈕貼底；送出後 autosizeChatInput() 收回高度。
5. RWD 未做（僅 @media print）；sidebar-bottom 兩排增加底部高度，folder-tree
   max-height:38%、paper-list flex:1 可吸收，小視窗仍可用但未專門優化。
