## §4 真因

對應 plan §3.3 + §3.8 修正 4：

1. **plan §3.3 書籍 RTT 卡死**：以「句子」為滑動單元、長文書籍切數百個 window、`_texttiling` 內 embedding RTT 序列卡死（Martin Buber《我與你》等書籍實測）；段落級滑動可降 ~80% 滑動次數
2. **plan §3.8 修正 4 regex 容錯**：v1 段落判定用 `'\n\n' in content_text` + `split('\n\n')`、對 Windows-encoded PDF（`\r\n`）或 translate 結果偶含空白（`\n \n` / `\n\t\n`）失效、長文書籍誤判為「整段一個 chunk」、`_texttiling` 不觸發、段落級提速無效
3. **`TILING_PARAGRAPH_THRESHOLD` 寫死**：書籍 vs 論文閾值需依場景調整、不應 hardcode
4. **`tiling_method` 標籤不一致**：B1 已標 `bypass`、其他路徑（delimiter / sentence / passthrough）未標、log / debug 時看不出走哪條路

## §5 修法

對應 plan §4.3 + §3.8 修正 4：

### 5.1 `settings.py` — `TILING_PARAGRAPH_THRESHOLD` env override（預設 30000）

```python
# Phase 4.7? MODEL-3 B3：段落級滑動觸發閾值（書籍 / 長論文）
# 詳見 .claude-logs/2026-05-22_MODEL-3_短文Bypass_公式穿透_段落滑動_plan.md §4.3
# 總字數 > 此值 → 段落級滑動（80% 滑動窗口減少、避免 RTT 卡死）
# 否則 → 既有句子 / delimiter 級滑動
TILING_PARAGRAPH_THRESHOLD = int(os.getenv("TILING_PARAGRAPH_THRESHOLD", "30000"))
```

### 5.2 `processor/tiling_processor.py` — `_PARAGRAPH_SPLIT_RE` regex（修正 4）

```python
# Phase 4.7? MODEL-3 B3 修正 4：段落切割容錯
# 容錯 Windows \r\n / 多餘空白（如 \n \n / \n\t\n）
# 依 plan §3.8 修正 4
_PARAGRAPH_SPLIT_RE = re.compile(r'\r?\n\s*\r?\n')
```

### 5.3 `_process_content` — `total_chars_hint` + `long_doc_mode` 切換 + `tiling_method` 標籤

關鍵變動：
- 簽名加 `total_chars_hint: int = 0`
- 計算 `long_doc_mode = total_chars_hint > TILING_PARAGRAPH_THRESHOLD`
- 切割模式 if/elif/else 三條路徑：
  - `long_doc_mode and _PARAGRAPH_SPLIT_RE.search(text)` → `split_mode='paragraph'`、regex split
  - `'\n\n' in text` → `split_mode='delimiter'`（既有）
  - else → `split_mode='sentence'`（既有 `_split_into_sentences`）
- 切割路徑：`new_block['tiling_method'] = split_mode`（paragraph / delimiter / sentence）
- 非切割路徑：`item_with_method.setdefault('tiling_method', 'passthrough')`

### 5.4 `_process_sections` — 遞迴傳遞 `total_chars_hint`

```python
def _process_sections(self, sections, total_chars_hint=0):
    for section in sections:
        if section.get('type') in ['abstract', 'references']:
            continue
        if 'content' in section:
            section['content'] = self._process_content(
                section['content'], total_chars_hint=total_chars_hint
            )
        if 'children' in section and section['children']:
            self._process_sections(section['children'], total_chars_hint=total_chars_hint)
```

### 5.5 `process()` — `total_chars` 傳遞到 `_process_sections`

`process()` 主入口的 non-bypass else branch、`_process_sections` call 加 `total_chars_hint=total_chars`：

```python
self._process_sections(data['sections'], total_chars_hint=total_chars)
```

（既有 `total_chars = self._estimate_total_chars(data)` 沿用 B1 ship 邏輯、不重複計算）
