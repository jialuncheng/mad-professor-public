## §5 修法

### 5.1 `tools/regen_rag.py` 新檔結構（348 行）

| 子命令 / 函式 | 行數 | 功能 |
|---|---|---|
| `cmd_check(owner_id) -> int` | ~40 | 用 `list_papers_with_chunks` JOIN paper × paper_chunks、印 `[OK]` / `[MISMATCH]`、return mismatch count 為 exit code（CI 用） |
| `cmd_regen(paper_db_id, owner_id, paper_uuid, force, dry_run)` | ~85 | 從 paper_chunks 讀 `raw_text` + `metadata_json` → `Document(page_content, metadata)` → `FAISS.from_documents(..., MAX_INNER_PRODUCT)` → `save_local` → `replace_paper_chunks` 更新 embedding_model → `write_index_meta_json` |
| `cmd_all(force, dry_run, owner_id)` | ~15 | `list_papers_with_chunks` → loop `cmd_regen`（Q5 單緒） |
| `cmd_init(owner_id, dry_run)` | ~90 | `sorted(OUTPUT_DIR.glob('*/*/vectors'))` → 過濾 orphan + 已有 chunks → `FAISS.load_local(...)` → `vs.docstore._dict.items()` → 重組 row（Q16 doc_type='')→ `replace_paper_chunks` + `write_index_meta_json` |
| `main()` argparse | ~50 | 6 子命令派發、`--paper` 需 `--owner` 檢查、`--check` 走 `sys.exit(mismatch_count)` |

**關鍵共用 helper**（C1 + C2 import、不重做）：
- `paper_manager.get_paper_db_id` / `list_papers_with_chunks` / `iter_paper_chunks` / `replace_paper_chunks`（C1）
- `processor.rag_processor.write_index_meta_json` / `CHUNK_FILTER_VERSION`（C2 已 ship 的 module-level helper、修正 4）
- `settings.OUTPUT_DIR` / `EMBEDDING_MODEL_NAME` / `EMBEDDING_OUTPUT_DIMENSIONS`（C1）
- `langchain_core.documents.Document`（與 C2 一致）
- `DistanceStrategy.MAX_INNER_PRODUCT`（與 C2 `_create_vector_store` 一致）

**`cmd_init` 反向導入細節**（修正 6）：
- 用 `sorted(OUTPUT_DIR.glob('*/*/vectors'))` 掃描所有 paper
- 跳過：① 沒有 `index.faiss` ② `owner_dir_name` 非整數 ③ `--owner` 過濾不符 ④ `get_paper_db_id` 回 None（orphan） ⑤ 已有 `paper_chunks` rows
- 用 `FAISS.load_local(str(vectors_dir), embedder, allow_dangerous_deserialization=True)` 載入
- `vs.docstore._dict.items()` 拿原 Document（langchain `InMemoryDocstore` 內部 dict）
- 每個 doc 組 row：`raw_text=doc.page_content`、`metadata_json=json.dumps(doc.metadata)`、`chunk_key=metadata['Header']`、`doc_type=''`（Q16）、`embedding_model/output_dimensions` 用當前 settings
