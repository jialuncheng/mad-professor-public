# 2026-05-20 pipeline 完整時間軸日誌補全（只加 log，零業務邏輯變更）

目標：看 log 即可還原 pipeline 完整時序——每 stage 耗時、Stage A/B 耗時、
MinerU 互動、_tmp 內容、_copy_images 各分支與結果。

## 原則遵守
- **只加 logger 訊息 + 純為 log 用的局部計時變數**（`_*_t0`/`_t`）+ 3 個
  `import time`（stdlib）。
- **未改**任何函式行為、控制流、錯誤處理、既有變數、既有 log（全保留）。
- 計時變數僅出現在 f-string，**不參與任何業務判斷**。

## B. log level（確認，未改設定）
`web_server._setup_logging()`：root=WARNING（console 只 WARNING）；但
`pipeline.log` RotatingFileHandler=**DEBUG**，掛在 logger
`pipeline_core` / `paper_manager` / `processor`（均 setLevel DEBUG）。
子 logger（`pipeline_core.PipelineCore`、`processor.pdf_processor.*` …）
經 hierarchy 傳播到上述 handler。→ **本次所有 INFO/DEBUG 會寫入
`logs/pipeline.log`**，無需 basicConfig，**未改 logging 設定**（改了反而
有破壞 console 安靜設計的風險）。看時間軸：`tail -f logs/pipeline.log`。
