## §4 真因

對應 plan §3.2 + §3.5 + §3.7：

1. **plan §3.2 公式破碎**：既有 `_merge_small_text_blocks` (`processor/tiling_processor.py:274`) 只允許 `type=='text'` 進緩衝區（L291）；非 text node 強制 flush（L311-318）→ formula 變硬截斷邊界
2. **plan §3.5 修正 1 公式拼接字元災難**：buffer 合併寫死 `"\n\n" + item['content']`、`text + formula + text` 合併變 3 個獨立段落、user 看到斷裂排版
3. **plan §3.7 修正 3 公式長度虛高造成截斷**：LaTeX 源碼如 `\sum_{i=0}^{n} \alpha_i \cdot \beta_i` 33 字元 > min_length（500）邊界判定的閾值；若按 size 判定可能誤觸 flush、把公式跟前後 text 截斷

**後果**：academic paper inline formula 周圍說明被分離、翻譯端拿不到公式完整語意上下文、品質下降。

### 5.2 改寫 `_merge_small_text_blocks`（含修正 1 + 修正 3）

```python
def _merge_small_text_blocks(self, content):
    if not content:
        return content

    result = []
    current_buffer = None
    buffer_last_appended_type = None  # 修正 1：追蹤最後合進 buffer 的實際 type

    for item in content:
        item_type = item.get('type')

        # 修正 3：formula 無條件合併（不走 size 判定）
        if item_type == 'formula':
            text = item.get('content', '') or ''
            if current_buffer is None:
                current_buffer = item.copy()
                buffer_last_appended_type = 'formula'
            else:
                # 修正 1：用最後合進的實際 type 拼接
                current_buffer['content'] = _join_content(
                    buffer_last_appended_type,
                    current_buffer.get('content', '') or '',
                    'formula', text
                )
                buffer_last_appended_type = 'formula'
            continue

        if item_type == 'text':
            text = item.get('content', '') or ''
            if len(text) < self.min_length:
                if current_buffer is None:
                    current_buffer = item.copy()
                    buffer_last_appended_type = 'text'
                else:
                    current_buffer['content'] = _join_content(
                        buffer_last_appended_type,
                        current_buffer.get('content', '') or '',
                        'text', text
                    )
                    buffer_last_appended_type = 'text'
            else:
                # 大 text、合 buffer 後 emit
                if current_buffer is not None:
                    current_buffer['content'] = _join_content(
                        buffer_last_appended_type,
                        current_buffer.get('content', '') or '',
                        'text', text
                    )
                    result.append(current_buffer)
                    current_buffer = None
                    buffer_last_appended_type = None
                else:
                    result.append(item)
        else:
            # 硬邊界（table / heading / image_caption / 其他 unknown type）
            if current_buffer is not None:
                result.append(current_buffer)
                current_buffer = None
                buffer_last_appended_type = None
            result.append(item)

    if current_buffer is not None:
        result.append(current_buffer)
    return result
```

**設計重點**：
- `buffer_last_appended_type` 追蹤最後合進的實際 type（同 B1 `_bypass_content` 的設計教訓、避免 text→formula→text 第二次合併誤判為 text+text）
- formula 永遠合進 buffer、size 判定只對 text 適用（修正 3）
- 全合併路徑用 B1 已 ship 的 `_join_content` helper、無重複實作
