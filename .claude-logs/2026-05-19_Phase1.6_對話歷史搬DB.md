## 新增 / 重寫 API（paper_manager）
- get_paper_db_id(owner_id, paper_uuid) -> Optional[int]：(owner,uuid)→Paper.id(INT PK)
- load_chat_history(paper_db_id:int, user_id:int) -> list[{role,content,grounding_sources?,created_at}]
  * query conversations where paper_id=db_id ORDER BY Conversation.id（id 序＝寫入序，避免撞秒）
  * grounding_sources 僅非空時附帶；created_at 轉 ISO 字串
- save_chat_history(paper_db_id:int, user_id:int, history:list)：整包覆寫
  * 先 delete 該 paper 既有 conversations，再批次 add；created_at 用 server_default（同 commit 同值，靠 id 排序）
  * 每筆可選 grounding_sources（list）→ 寫 JSON 欄；無則 None
- delete_conversations(paper_db_id:int)：顯式刪（刪 paper 時 DB 已 cascade，此為輔助）

簽名變更：load/save_chat_history 由 (output_dir,owner_id,paper_uuid) → (paper_db_id,user_id)。
所有 active 呼叫端（web_server 3 處）已同步。

## web_server 端點調整（URL 不變）
- GET /api/papers/{paper_uuid}/chat/history：get_paper_db_id→無則回 []；否則 load_chat_history(db_id,uid)
- POST /api/papers/{paper_uuid}/chat/history：get_paper_db_id→無則 404；save_chat_history(db_id,uid,messages)
- GET /api/papers/{paper_uuid}/chat/export：get_paper_db_id→load_chat_history
注意：規格提到的 DELETE /cleanup_history 端點現有 web_server 不存在、前端也不呼叫；
刪 paper 已由 Phase 1.5 delete_paper → DB ON DELETE CASCADE 連帶刪 conversations，
故不新增該未用端點（避免無用/未授權面）；paper_manager.delete_conversations 已備供未來使用。

## 對前端的影響（saveChatHistory body 改變）
舊：body messages = [{role,content}]（content 對 assistant 用 innerText，會混入來源文字）。
新：
- done 分支：有 grounding_sources 時 aiMsg.dataset.groundingSources=JSON 並 renderSources()

- web_server 端點一律先 get_paper_db_id(owner,uuid) 轉換，再傳 INT 給 paper_manager

## ⑧ 順序 / 時區
- created_at：models 用 server_default=func.now()；批次 insert 同 commit 可能同值
- 解法：load 一律 ORDER BY Conversation.id（自增 id＝寫入順序，穩定）
- created_at 僅作顯示用途回傳（ISO），不參與排序

## ⑨ grounding_sources 流程（持久化閉環）
user 問 → SSE done chunk 帶 grounding_sources（ai_core 既有）→ 前端 dataset 記下 + renderSources
→ finish 時 saveChatHistory POST（body assistant entry 含 grounding_sources）
→ web_server → paper_manager.save_chat_history 寫 conversations.grounding_sources(JSON)
→ 重啟後 loadChatHistory 讀回並 renderSources。
