### 5.2 `processor/tiling_processor.py` 加 `_join_content` module-level helper（修正 1）

```python
def _join_content(prev_type: str, prev_text: str,
                  next_type: str, next_text: str) -> str:
    """根據兩個節點的 type 決定拼接字元、防禦 inline formula 排版災難。"""
    if prev_type == 'text' and next_type == 'text':
        return prev_text + "\n\n" + next_text
    return prev_text + " " + next_text
```

### 5.5 新增 `_estimate_total_chars` / `_bypass_sections` / `_bypass_content`

`_bypass_content` 核心邏輯（含修正 1 + 修正 2）：

```python
def _bypass_content(self, content):
    """合併相鄰 text+formula、保留 non-text 原始 index。"""
    result = []
    buffer = None
    buffer_first_index = None
    buffer_last_appended_type = None  # 修正 1：追蹤實際拼接 type

    for item in content:
        item_type = item.get('type')
        if item_type in ('text', 'formula'):
            if buffer is None:
                buffer = item.copy()
                buffer_first_index = item.get('index', 0)
                buffer_last_appended_type = item_type
                buffer['part'] = 0
                buffer['tiling_method'] = 'bypass'
            else:
                # 修正 1：用最後合進的 type、不是 buffer 總 type
                buffer['content'] = _join_content(
                    buffer_last_appended_type, buffer.get('content', ''),
                    item_type, item.get('content', '')
                )
                buffer_last_appended_type = item_type
        else:
            # non-text/formula：硬截斷 + 保留原始 index（修正 2）
            if buffer is not None:
                buffer['index'] = buffer_first_index
                result.append(buffer)
                buffer = None
                buffer_first_index = None
                buffer_last_appended_type = None
            item_copy = item.copy()
            item_copy['part'] = 0
            # 修正 2：絕不重寫 index
            result.append(item_copy)

    if buffer is not None:
        buffer['index'] = buffer_first_index
        result.append(buffer)
    return result
```

⚠ 實作時發現的細節：原 plan §4.1 用 `buffer.get('type', 'text')` 當 prev_type、實際上會錯—— buffer 初始化用第一個 item 的 type、合進 formula 後仍是 'text'、下次再合 text 會走 text+text → `\n\n` 路徑（正確應走 formula+text → 空格）。**改成追蹤 `buffer_last_appended_type`**——對應的 pytest `test_inline_formula_preserved_with_space_join` 已守住此行為。
