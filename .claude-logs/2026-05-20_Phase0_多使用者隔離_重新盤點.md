### A-2 認證層

- `settings.py:25–27`：
  ```python
  AUTH_USERNAME = os.getenv("AUTH_USERNAME", "admin")
  AUTH_PASSWORD_HASH = os.getenv("AUTH_PASSWORD_HASH", "")
  SESSION_SECRET = os.getenv("SESSION_SECRET", "")
  ```
- 啟動 sanity 警告（web_server.py:125–128）：SESSION_SECRET / HASH 未設都
  WARN。
- **SessionMiddleware**：web_server.py:154–161（cookie `session`、HTTPS 限
  production、same_site=strict、max_age=None）
- **`auth_guard` middleware**：web_server.py:144（`/login`、`/logout`、
  `/api/health`、`/static/login*` 為 public，其餘必須 `session["user"]`，
  API 缺則 401 JSON、其餘 302 `/login`）
- **登入**（web_server.py:176–207）：bcrypt 驗證 `(username == AUTH_USERNAME
  && bcrypt.checkpw(password, AUTH_PASSWORD_HASH))` → 成功 `request.session
  ["user"] = username`。**目前 hardcode 比對 `settings.AUTH_USERNAME`
  只一筆**。
- **`get_current_user`**（web_server.py:236–244）：從 `session["user"]`
  讀 username → `paper_manager.get_user_by_username(username)` 取 DB User
  row → 回 `CurrentUser(id, username)` namedtuple。若 username == admin
  但 DB 無此 row，呼叫 `paper_manager.ensure_admin()` lazy-create。
- **每個 /api endpoint 注入 `CurrentUser = Depends(get_current_user)`**：
  共 17 個端點（見 A-5），無例外。

### A-3 檔案系統層

- **OUTPUT_DIR**：`settings.OUTPUT_DIR`，預設 `<repo>/output`
- **路徑規範**（`paper_manager.py:89–137`）：所有 paper-related 檔皆走
  `paper_dir(output_dir, owner_id, paper_uuid)` = `output/{owner_id}/{paper_uuid}/`：
  - `article_zh / article_en / rag_tree / rag_md / vectors / images / original_pdf`
    皆在此目錄下
  - `original_pdf` 檔名 = `{paper_uuid}.pdf`（Phase 4.7b；含舊資料 fallback
    `original.pdf`）
- **paper_uuid**：`paper_manager.sanitize_paper_id(filename)` 處理→
  `re.sub(r'[^\w\-]','_', stem)` + 連續底線去重。
  - **撞名可能性**：同一 owner 上傳 `foo.pdf` 兩次 →
    `(owner_id, paper_uuid)` unique constraint 擋；不同 owner 上傳同檔名 →
    各自 namespace 不衝突。**檔案系統層已隔離乾淨**。
- **無 per-user 額外處理**：所有寫入路徑都已 enforce owner_id（pipeline_core
  傳 owner_id → paper_dir / upsert_paper）。
