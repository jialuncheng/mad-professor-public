## §4 修法說明

### 4.1 `renderMarkdownWithMath`（plan §2.1 七步、§2-5 無 lookbehind 正則、步驟 7 ESC 還原）
```js
function renderMarkdownWithMath(raw) {
  if (raw == null) raw = '';
  const MO = '', MC = '';     // math 佔位哨兵（Unicode PUA）
  const codeBlocks = [], mathBlocks = [];
  let t = String(raw);
  t = t.replace(/(```[\s\S]*?```|`[^`\n]+?`)/g, m => { codeBlocks.push(m); return '__CODE_PLACEHOLDER_'+(codeBlocks.length-1)+'__'; }); // 1
  t = t.split('\\$').join('__ESC_DOLLAR__');                                          // 2 護跳脫（無 lookbehind）
  t = t.replace(/\$\$([\s\S]+?)\$\$/g, (m,f) => { mathBlocks.push({formula:f,displayMode:true}); return MO+(mathBlocks.length-1)+MC; });  // 3 block
  t = t.replace(/\$([^\s$](?:[^$]*?[^\s$])?)\$(?!\d)/g, (m,f) => { mathBlocks.push({formula:f,displayMode:false}); return MO+(mathBlocks.length-1)+MC; }); // 4 inline texmath
  t = t.replace(/__CODE_PLACEHOLDER_(\d+)__/g, (m,i)=>codeBlocks[i]).split('__ESC_DOLLAR__').join('\\$'); // 5 還原 code/\$（僅 tempText）
  let html = marked.parse(t);                                                          // 6
  html = html.replace(new RegExp(MO+'(\\d+)'+MC,'g'), (m,i)=>{                          // 7 回填
    const item=mathBlocks[i]; if(!item) return m;
    const clean=item.formula.replace(/__ESC_DOLLAR__/g,'\\$');                          // 步驟 7 ESC 還原鐵律
    try { return katex.renderToString(clean,{displayMode:item.displayMode,throwOnError:false}); }
    catch(e){ return '<span class="katex-error" style="color:#cc0000">'+clean+'</span>'; }
  });
  return html;
}
```

### 4.2 ⚠️ 對 tasks/plan 規格之**必要 deviation**：math 佔位符改 Unicode PUA 哨兵
- **規格原訂**：tasks §8 C2 / plan §2.1 用 `__MATH_PLACEHOLDER_N__`。
- **執行期發現缺陷（spike 實證）**：math 佔位**穿透 marked.parse**（步驟 6→7），而 `__x__` 是 **marked GFM 雙底線粗體**——實測 `marked.parse('文字 __MATH_PLACEHOLDER_0__ 文字')` → `<p>文字 <strong>MATH_PLACEHOLDER_0</strong> 文字</p>`，步驟 7 regex `/__MATH_PLACEHOLDER_(\d+)__/` **撈不到**、數學**靜默不渲染**。
- **修法**：math 佔位改 **Unicode PUA 哨兵** `{idx}`（不可見、零 markdown 語意、零撞內容；spike 證 marked block/inline 皆原樣穿透）。
- **範圍最小化**：僅 math 佔位改 PUA；`__CODE_PLACEHOLDER__`/`__ESC_DOLLAR__` 於步驟 5（marked.parse **前**）即還原、不穿透 marked，故維持 `__x__`。
- 此為**正確性必要修正**（規格佔位會使整個功能失效），已於碼內註解 + 本報告明載。
