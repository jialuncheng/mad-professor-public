## §4 修改說明

### (a) `renderSources` 節點化前後
**前**（字串拼接·uri/title 直插）：
```js
  div.innerHTML = '來源：' + sources.map(s =>
    `<a href="${s.uri}" target="_blank" rel="noopener">${s.title}</a>`
  ).join('、');
```
**後**（純 DOM 組裝）：
```js
  div.appendChild(document.createTextNode('來源：'));
  sources.forEach((s, i) => {
    if (i > 0) div.appendChild(document.createTextNode('、'));
    const a = document.createElement('a');
    a.textContent = s.title || s.uri || '';                      // 標題永為純文字
    if (typeof s.uri === 'string' && /^https?:\/\//i.test(s.uri.trim())) {
      a.href = s.uri.trim(); a.target = '_blank'; a.rel = 'noopener';
    }                                                            // 非 http(s)（javascript:/data:…）不設 href
    div.appendChild(a);
  });
```

### (b) `normalizeAcademicHeader` 五欄單體消毒
`extractField(...)` 外包 `DOMPurify.sanitize(...)` ×5（authors/date/venue/doi/keywords）——值雖以 `textContent` 提取（純文字），但**插回 `innerHTML` 時字面 `<img onerror=…>` 會轉活** → 逐欄消毒。靜態 `<div class="header-*">` 模板字串本身不進 sanitizer（僅變數）。

### (c) `renderPapers` 標題單體消毒（靜態模板保留細節）
`resolveDisplayTitle/Subtitle(p)` 外包 sanitize 後才進模板字串——**消毒發生在變數層**、模板字面量（`data-tip="文件選單"` 按鈕 + `<svg viewBox…>` 三點圖示）完全不經 sanitizer、byte 原樣（守衛斷言驗證存在性）→ tooltip 與選單按鈕行為零變。

### (d) 守衛 +2（含一次切片錨修正）
- ⑥ `renderSources`：無 `href="${s.uri}"`/`${s.title}` 插值 + 含 `createElement('a')`/`textContent`/`https?` 白名單。
- ⑦ header **恰 5 次** sanitize 呼叫（計數防漏欄）+ papers 兩標題消毒 + `data-tip`/`<svg>` 靜態模板守恆。
- 執行期修正：切片終點初用 `papersInCurrentFolder`（實定義於 renderPapers **前** L1363）→ 改 `async function loadPapers`（紅→綠）。
