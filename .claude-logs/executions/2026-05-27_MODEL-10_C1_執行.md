## §4 修法說明

### 4.1 `processor/pdf_processor.py` — `__init__` MINERU_TIMEOUT 防禦性載入

**原始**（L33 之後）：
```python
self.MINERU_PAPER_NAME = os.getenv("MINERU_PAPER_NAME", "original")
self.logger.debug("初始化 PDF 處理器（MinerU API 模式）")
```

**修改後**：
```python
self.MINERU_PAPER_NAME = os.getenv("MINERU_PAPER_NAME", "original")
try:
    self.MINERU_TIMEOUT = int(os.getenv("MINERU_TIMEOUT", "1800"))
except (ValueError, TypeError):
    self.logger.warning("MINERU_TIMEOUT 設定值無效，退回預設 1800 秒")
    self.MINERU_TIMEOUT = 1800
self.logger.debug("初始化 PDF 處理器（MinerU API 模式）")
```

防禦邏輯：`os.getenv("MINERU_TIMEOUT", "1800")` 若未設定則 fallback 預設字串 `"1800"`，再包裹在 try/except 中以防非數字字串（如 `"abc"`）導致 `ValueError` 崩潰。

### 4.2 `processor/pdf_processor.py` — `process()` timeout 動態化

**原始**（L71/現 L76）：
```python
timeout=300
```

**修改後**：
```python
timeout=self.MINERU_TIMEOUT
```

書籍 PDF 處理通常需 10-30 分鐘（600-1800 秒），原固定 300 秒必然觸發 `ReadTimeout`。

### 4.3 `processor/pdf_processor.py` — `_copy_images()` Priority 2 廢棄 warning

**原始**（Priority 1 return 後）：
```python
self.logger.info(
    f"[copy_images] _tmp 無圖（{tmp_images}）→ 退回 server 端取圖"
)
```

**修改後**：
```python
self.logger.warning(
    "[copy_images] ZIP 無圖，退回已過期 (Deprecated) 的 SCP 遠端取圖機制，"
    "請確認 MinerU 服務是否支援 return_images"
)
```

**Logging SOP 合規判定**：此路徑為正常降級機制（Priority 1 ZIP 無圖時退回舊版 Priority 2），非程式拋出之 Exception。依 logging SOP，`WARNING` 適用「可容忍的非致命異常」場景，**嚴禁加 `exc_info=True`**（plan §2.1 及 tasks §8 C1 均已明確標注）。

### 4.4 `.env.example` — MINERU_TIMEOUT 新增

在 `MINERU_OUTPUT_DIR=` 之後追加：
```bash
# MinerU HTTP 請求超時（秒）。書籍 PDF 通常需 10-30 分鐘，建議設 1800 以上。
# 若設為非數字字串，程式自動退回預設 1800 秒（防禦性容錯）。
MINERU_TIMEOUT=1800
```
