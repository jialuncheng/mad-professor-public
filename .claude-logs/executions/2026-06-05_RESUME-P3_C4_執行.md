## §4 修法說明
```python
        # === [RESUME-P3 C4 START] ===  （dispatch 前）
        degraded = (not is_zh) and bool(sections) and self._is_heading_degraded(sections)
        if degraded:
            logger.warning("[PIPE-RESUME P3] %s heading 退化（…）→ 降級整檔翻譯 fallback",
                           ctx.paper_id, len(sections))
        # === [RESUME-P3 C4 END] ===
        if is_zh:                          zh_text = full_text
        elif sections and not degraded:    zh_text = self._restore_sections_markdown(...)   # C4 加 not degraded
        else:                              zh_text = self._translate_whole(full_text, inj, tr, True)  # 退化/無 section fallback

        # 私有：_is_heading_degraded（攤平 heading、heading<2 或 max/total>0.85）
        #       _flatten_sections（遞迴攤平 children）/ _own_text_len（單一 section 自身 text 長度）
```
- 偵測以「每 heading **自身** content 文字」計（不把 children 計入 parent），避免正常巢狀履歷誤判。
- 退化 → 復用 C3 既有 `_translate_whole`（整檔 1 次翻譯），不新增翻譯路徑。
