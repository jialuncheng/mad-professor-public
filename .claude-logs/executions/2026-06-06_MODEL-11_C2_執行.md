## §4 真因與修法

### §4.1 真因
plan §1/§3：`gemini-embedding-2` 下 `_embed_batch(contents=[N 段])` 經 SDK `t_contents()` 併成 1 → `len != len(batch)` 必拋 → `embed_documents` 永遠退序列逐筆、log 誤標 `embedding_429`。C1 已把預設模型換 `gemini-embedding-001`（文字真批次、N→N），C2 配套把 `embed_documents` 從固定 32 段切分改為 **token-aware 貪婪封批**（守 -001 的 20,000 token/請求 + 250 段上限），並把誤導 log 正名。

### §4.2 修法（`config.py` 唯一改檔）

1. **import 三常數**（`# === [MODEL-11 C2 START/END] ===`，L19-26）：
   ```python
   from settings import (
       EMBEDDING_BATCH_MAX_ITEMS,
       EMBEDDING_BATCH_MAX_TOKENS,
       EMBEDDING_MAX_TOKENS_PER_ITEM,
   )
   ```

2. **過時註解更新**（MODEL-9-OPT C2 頂部，L88 附近）：移除「batch=32」「向量值逐一相同、不影響 Golden Baseline」過時宣稱，改註：
   > ⚠️ MODEL-11 起：embed_documents 改 token-aware 拆批（廢固定 batch=32）；且 settings 預設模型換 gemini-embedding-001（文字真批次 + task_type 生效）→ 向量值改變，**不再** byte 等價舊狀，各環境須跑 regen_rag.py --all 全量重嵌 + 與相關改動合併重捕 Golden Baseline。

3. **embed_documents 重構**（`# === [MODEL-11 C2 START/END] ===` 包裹方法體）：
   - 巢狀 `_flush(batch)` helper（封批送 `_embed_batch`、失敗退逐筆 `_embed_one` 真 fallback；用 `state` dict 容器更新 batch_no/done，避免 `nonlocal`）。
   - 貪婪封批主迴圈：
     ```python
     cur_batch, cur_tokens = [], 0
     for text in texts:
         est = max(1, len(text))  # 字元數作 token 上界保守估值（CJK 安全、不低估）
         if est > EMBEDDING_MAX_TOKENS_PER_ITEM:
             self.logger.warning('單段 token 估值超上限',
                 extra={'extra_fields': {'event': 'embedding_oversized_item', 'est_tokens': est}})
         if cur_batch and (len(cur_batch) >= EMBEDDING_BATCH_MAX_ITEMS
                           or cur_tokens + est > EMBEDDING_BATCH_MAX_TOKENS):
             _flush(cur_batch); cur_batch = []; cur_tokens = 0
         cur_batch.append(text); cur_tokens += est
     _flush(cur_batch)   # 殘留收尾
     return embeddings
     ```
   - **log 正名**（`_flush` except 區塊）：
     ```python
     extra={'extra_fields': {
         'event': 'embedding_batch_fallback',   # 原 'embedding_429'
         'reason': str(e)[:200],                 # 新增：區分真 429/timeout/數量不符
         'batch_no': batch_no, 'batch_size': len(batch),
     }}
     ```

4. **保留不變**：`_embed_batch`（簽名 + `len(result.embeddings) != len(batch)` 校驗，-001 變長 N→N 直通通過）/ `_embed_one` / `embed_query`（RETRIEVAL_QUERY）/ `embed_image`。task_type 程式碼本已正確（DOCUMENT 整批 / QUERY 單筆），換模型後 API 自動生效、無需改碼。
