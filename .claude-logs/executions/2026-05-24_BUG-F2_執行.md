## 2. 子段順序（TDZ-aware 3 段 + upload handler 移位）

依評估報告 v2 §B B2.3，BUG-F2 落地順序：

```
─── BUG-F2 子段執行順序（防 TDZ ReferenceError） ───

【第一段】static/index.html L1804-1814（dropdownAPI IIFE 之前）
  · const THEME_KEY + savedTheme = localStorage.getItem(THEME_KEY)
  · if (savedTheme) { themeLink.href = ... }   ← 只立即套用 themeLink
  · 不碰 dropdown 顯示值（dropdownAPI 還未 init）
  · L1811 outer labels duplicate 已刪除
  · 理由：themeLink 必須頁面渲染前決定、避免閃 fallback

【中間區塊】theme-btn / theme-ok-btn / theme-upload-btn click handler 等
  · 無 dropdownAPI 依賴、留原位安全

【第二段】static/index.html L1903-1978（dropdownAPI IIFE 宣告）
  · const dropdownAPI = (() => {
       const DOC_TYPES = [...];
       const THEMES = [...];                 ← 4 主題（mies/kahn/kandinsky/nara）
       const themeLabels = Object.fromEntries(THEMES);   ← 統一 label 管理
       setupOne(doc-type-dropdown, DOC_TYPES);
       setupOne(theme-dropdown, THEMES);
       function setupOne(dd, items) { ... 原邏輯不變 ... }
       return {
         addTheme(name, label) { themeLabels[name] = label; THEMES.push(...); }
         getThemeLabel(name) { return themeLabels[name] || name; }
       };
     })();
  · window.dropdownAPI = dropdownAPI;        ← 對外暴露

【第三段】static/index.html L1980-1989（IIFE 之後、savedTheme sync）
  · if (savedTheme) {
       dropdownAPI.addTheme(savedTheme);      ← 自訂 theme 動態註冊
       dd.dataset.value = savedTheme;
       dd.querySelector('.dropdown-value').textContent = dropdownAPI.getThemeLabel(savedTheme);
     }

【upload handler】static/index.html L1991-2026（IIFE 之後、保險防 TDZ）
  · document.getElementById('theme-upload-input').addEventListener('change', ...)
  · 原 L1831 已搬到此處（IIFE 之後）
  · handler body 呼叫 dropdownAPI.addTheme(themeName) + getThemeLabel(themeName)
```

**為什麼這個順序很關鍵**：
- `const dropdownAPI = (() => {...})();` 在第二段宣告——**在它之前**任何 `dropdownAPI.xxx` 呼叫都會炸 `ReferenceError: Cannot access 'dropdownAPI' before initialization`（TDZ）
- 第一段只設 themeLink、不碰 dropdownAPI、安全
- 第三段在 IIFE 之後、dropdownAPI 已 init、可安全 sync dropdown 顯示值
- upload handler 雖然 body 透過 closure 延後求值（user click 時才執行）、但保險起見整段 addEventListener 註冊也搬到 IIFE 之後（v2 明示）
