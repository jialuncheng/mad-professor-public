## §4 修法說明

### §4.1 `static/index.html` — scroll handler 加 ctx-popup 過濾

**定位**（以 grep 動態確認，非依賴行號）：
```bash
grep -n "addEventListener.*scroll.*closePopups" static/index.html
# 1622:window.addEventListener('scroll', closePopups, true);
```

**Before（L1622）**：
```javascript
  // popup 開啟期間捲動 / 縮放視窗就關閉，避免錨點失準
  window.addEventListener('scroll', closePopups, true);
```

**After**：
```javascript
  // popup 開啟期間捲動 / 縮放視窗就關閉，避免錨點失準
  window.addEventListener('scroll', (e) => {
    // 🟢 RAG-13-HOTFIX-1：若滾動源自彈出選單內部，則忽略，防止誤判關閉
    if (e.target.closest && e.target.closest('.ctx-popup')) return;
    closePopups();
  }, true);
```

**設計決策**：
- `e.target.closest && e.target.closest('.ctx-popup')` — 雙重防禦：先確認 `closest` API 存在（ES5 相容），再確認事件源在 `.ctx-popup` 範疇內
- 第三參數仍保留 `true`（捕獲階段），確保主頁面滾動仍能正常觸發 `closePopups()`
- L1623 `window.addEventListener('resize', closePopups)` 完全未動
