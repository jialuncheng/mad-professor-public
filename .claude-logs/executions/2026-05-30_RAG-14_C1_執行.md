### §4.5 `static/index.html` — JS `sendMessage` × 過濾

```javascript
/* 舊 */
const query = (input.textContent || '').trim();

/* 新 */
// × 按鈕過濾：clone node → 移除 .hashtag-token-remove → 取 textContent（C1 RAG-14）
const _tmpDiv = input.cloneNode(true);
_tmpDiv.querySelectorAll('.hashtag-token-remove').forEach(btn => btn.remove());
const query = (_tmpDiv.textContent || '').trim();
```

`input.cloneNode(true)` 深複製 contenteditable div，再從 clone 中移除所有 `.hashtag-token-remove` 按鈕（即 hashtag token 的 × 刪除鈕），最後取 `textContent` 作為送出的 query。原始 DOM 不受影響，× 按鈕仍保留於 UI。

**根因**：不過濾時，hashtag token `<span>#tag<button class="hashtag-token-remove">×</button></span>` 的 textContent 為 `#tag×`，`×` 混入查詢字串送至後端，產生 `#sstx` 等污染。
