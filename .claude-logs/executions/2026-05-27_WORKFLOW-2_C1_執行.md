## §4 修法說明

### §4.1 修法策略

5 個模板的提示詞本體（`## 提示詞本體（複製此段以下全部內容使用）` 之後的區段）中，在 AI 角色扮演起始行之前插入：

1. **元數據審計塊模板**（4 個原無此欄的模板：plan / tasks / check / sop）
2. **`## 🗄️ 第一步：主動歸檔本提示詞` 區塊**（全部 5 個模板）

同時將末段 `## 提示詞歸檔指令` 改為 `## 備援提示詞歸檔指令（baron 手動參考）`，並在其頂部加入：
```
> ℹ️ AI 主動歸檔已由上方「第一步」區塊處理。以下 bash 指令僅供 baron 手動備援用。
```

### §4.2 各模板插入位置

| 模板 | 插入位置（AI 角色扮演起始行前） | 原有元數據塊 |
|---|---|---|
| `template_prompt_for_plan.md` | `你現在扮演 **規劃顧問**` 前 | 無 → 新增 |
| `template_prompt_for_tasks.md` | `你現在扮演 **Claude Code**，請依以下指令將 plan 拆分` 前 | 無 → 新增 |
| `template_prompt_for_run.md` | `你現在扮演 **Claude Code**，請執行以下指定的單一 Commit/OP` 前 | **已有** → 保留，僅插入第一步 |
| `template_prompt_for_check.md` | `你現在扮演 **Claude Code**，請對以下任務執行 Conformance 驗收` 前 | 無 → 新增 |
| `template_prompt_for_sop.md` | `你現在扮演 **Claude Code**，請撰寫以下領域的 SOP 手冊` 前 | 無 → 新增 |

### §4.3 第一步區塊核心內容（各模板一致）

```markdown
## 🗄️ 第一步：主動歸檔本提示詞（必須先完成，才准進入下一步）

**你現在必須立即執行以下歸檔動作，完成前嚴禁進行任何讀檔、grep 或代碼操作：**

1. **寫入提示詞歸檔檔**：呼叫寫檔工具，將本次對話的完整提示詞（含元數據塊與全部正文）寫入：
   `.claude-logs/prompts/<YYYY-MM-DD>_<任務編碼>_<階段>_提示詞.md`
   格式嚴格依 `.claude-logs/prompts/README.md §3 檔案格式`。

2. **更新 INDEX.md**：在 `.claude-logs/prompts/INDEX.md` 的對應分類下補登新條目，並在 `## 依時間排序` 首行插入新條目，超過 15 筆則刪除最舊一筆。

3. **確認完成後繼續**：歸檔成功後，在此回覆「✅ 提示詞已歸檔：`<檔案路徑>`」，然後繼續執行後續步驟。
```
