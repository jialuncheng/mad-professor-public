### 5.1 `paper_manager.py` 加 `set_paper_tags` helper（+55 行）

依 UI Fixes Plan v3 L23-31、執行計劃 §4.1：

```python
def set_paper_tags(session, owner_id, paper_uuid, tags) -> Paper:
    """覆寫式整批寫入 user_tags 到 Paper.metadata_json（RAG-1 R1 子項 A）。"""
    p = session.query(Paper).filter_by(
        owner_id=owner_id, paper_uuid=paper_uuid
    ).one_or_none()
    if p is None:
        raise ValueError("論文不存在")

    # 安全解析既有 metadata、保留其他 key
    try:
        meta = json.loads(p.metadata_json) if p.metadata_json else {}
        if not isinstance(meta, dict):
            meta = {}
    except (json.JSONDecodeError, TypeError):
        meta = {}

    # 過濾 None / 非字串 / 空字串（strip 後）
    cleaned = []
    for t in (tags or []):
        if isinstance(t, str):
            s = t.strip()
            if s:
                cleaned.append(s)
    meta["user_tags"] = cleaned
    p.metadata_json = json.dumps(meta, ensure_ascii=False)
    session.commit()
    logger.info(f"標籤寫入: owner={owner_id} {paper_uuid} → tags={cleaned}")
    return p
```

**重點**：
- 整批覆寫策略（跟 R3 `_apply_folder_path_tags` 的 append + de-dup 互補、§4.2.4）
- metadata_json corrupt 時 graceful 重置為 `{}`
- 不寫 lowercase 標準化——v3 規劃在 R2 整合 `_normalize_tag()` 共用 helper（避免本 commit 範圍蔓延）
