### 1. `processor/md_restore_processor.py` — 加 `_preserve_pipe_table()` helper + L683-684 改寫

**改動 1：新增 helper method**（在 `_write_to_md` 與 `_process_section` 之間）：

```python
def _preserve_pipe_table(self, text: str) -> str:
    """Phase 4.7? RAG-8: 單 \\n 改 \\n\\n、但 pipe table 區塊（以 | 開頭連續行）保留原 \\n。
    ...
    """
    import re
    lines = text.split('\n')
    out_lines = []
    in_table = False
    for line in lines:
        is_table_row = bool(re.match(r'^\s*\|', line))
        if is_table_row:
            if not in_table and out_lines and out_lines[-1].strip():
                out_lines.append('')  # 進入 table 前補空行
            in_table = True
            out_lines.append(line)
        elif in_table:
            in_table = False
            if line.strip():
                out_lines.append('')  # 離開 table 補空行
            out_lines.append(line)
        else:
            out_lines.append(line)
    text = '\n'.join(out_lines)
    # 一般 prose 單 \n 仍轉 \n\n（避開 | 開頭行）
    text = re.sub(r'(?<!\|)(?<!\n)\n(?![\n\|])', '\n\n', text)
    return text
```

**改動 2：`_process_section` 內 L683-684**（原 regex 替換為 helper 呼叫）：

