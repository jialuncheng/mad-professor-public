## §4 修法說明
```python
    # === [RESUME-P3 C3 START] ===
    def run_phase3(self, ctx) -> BilingualMarkdownSpec:
        ...
        is_zh = source_lang.startswith("zh")
        sections = (ctx.ingestion.tiles if ctx.ingestion else []) or []
        full_text = self._read_source_text(ctx)
        inj = InjectionContext(lcc=…, glossary=…, zh_summary=gspec.translated_abstract,
                               domain_name=…, doc_type="resume", constraints=_RESUME_CONSTRAINTS)
        tr = Translator()
        if is_zh:           zh_text = full_text                       # 不重譯
        elif sections:      zh_text = self._restore_sections_markdown(sections, inj, tr, True)
        else:               zh_text = self._translate_whole(full_text, inj, tr, True)  # 退化 fallback
        en_text = full_text
        ... 寫 zh/en md、交付 BilingualMarkdownSpec（欄位不變）...

    # 私有：_restore_sections_markdown（遞迴）/ _restore_one_section（標題#×level + content 分流 + children）
    #       / _translate_whole（整檔 fallback 基礎）/ _t（空白略過的單元翻譯）
    # === [RESUME-P3 C3 END] ===
```
- formula/figure/table → 保留 `item['content']` 原文；text → `_t(content,…,"content")`；標題 → `_t(title,…,"title")`。
- `tr = Translator()` 單一實例逐單元共用。
