## §4 修法說明
mock 隔離（繞 singleton + httpx）+ A/B/C 以 `monkeypatch.setattr(time, "sleep", noop)` 跳過退避 sleep 加速：
```python
def _make_instance_with_mock_client():
    instance = EmbeddingModel.__new__(EmbeddingModel)   # _api_semaphore 為 class 屬性、自動共用
    instance.client = MagicMock(); instance.model = "gemini-embedding-2"
    instance.logger = logging.getLogger("config")
    return instance

# A 429 退避：side_effect 首呼 raise "429"、次呼回 _resp([[3,4]]) → assert calls==2 + norm==1
# C 批次降級：contents>1 → raise 429（耗盡）；contents==1 → 依文字回固定向量 → assert 保序 + caplog "逐筆"
# D 限流：side_effect 記錄併發峰值 + time.sleep(0.05) 製造重疊；ThreadPoolExecutor(2N+2) → assert max<=EMBEDDING_MAX_CONCURRENT
```
