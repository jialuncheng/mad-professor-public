## §4 修法說明（`# === [META-NORM C2 START/END] ===` 包裹、逐段鏡像 DomainNormalizer）

### `processor/meta_normalizer.py`
- **常數**：`_RESERVED_MAPPING`（title/作者/venue/期刊/doi… → 凍結合約欄、BS1）+ `_RESERVED_PREFIX="__reserved__:"`（標記交 P1 回填）+ `_GENERIC_KEYS` 黑名單（date/time/name/title/class/type/status/id/no/code/user、Q9）+ `_META_ALIGN_SYSTEM_PROMPT`（比對既有 canonical、保守同義才併·Q2）。
- **MetaNormalizer**（依賴注入 llm/session_factory，測試可 mock）：
  - `_normalize_key`：`.strip().lower()`。
  - `_cache_lookup`：MetaFieldAlias 唯讀極短 session。
  - `_existing_canonicals`：讀既有 MetaField 全集供 LLM 比對。
  - `_llm_classify`：`LLM_DOMAIN_MODEL` + **temp=0**（Q2）+ **交易外**；解析 JSON `{canonical,label_zh,label_en}`、canonical 收 snake_case。
  - `_register_and_cache`：`with session.begin()` + `on_conflict_do_nothing` 註冊 MetaField（label 缺以 canonical 兜底·BS4、sort_weight=100）；**黑名單 `write_alias=False` 不寫快取**（Q9/BS3）。
  - `normalize`：三路分流（reserved→映射標記不入庫不問 LLM / 黑名單→不查快取直接 LLM / 非黑名單→快取查→未命中 LLM+註冊）；**單欄 try/except 降級原樣 + `logger.error(exc_info=True)`**、不阻斷。
- 模組級單例 + 公開 `normalize_fields`：旗標 `LLM_USE_META_NORM` False→直回原樣（0 DB/0 LLM）。
