## §4 修法說明

### 4.1 fetch 腳本（`tools/fetch_frontend_vendor.sh`）
`npm pack katex@0.16.47` → 解 tarball → copy `dist/katex.min.css`/`katex.min.js` + `dist/fonts/*.woff2`（僅 woff2、瘦身）至 `static/vendor/katex/` → 印 SHA-256 校驗。離線/GFW 部署重跑可重現。

### 4.2 head 載入（`static/index.html` L8 marked 之後）
```html
<script src="https://cdnjs.cloudflare.com/ajax/libs/marked/9.1.6/marked.min.js"></script>
<!-- === [RAG-12 C1] === 自託管 KaTeX 0.16.47（前端數學渲染、離線/GFW；接線見 RAG-12 C2/C3） -->
<link rel="stylesheet" href="/static/vendor/katex/katex.min.css">
<script src="/static/vendor/katex/katex.min.js"></script>
<!-- === [RAG-12 C1 END] === -->
```
KaTeX 全域可用（`window.katex`），**尚未接線**（行為等價）。

### 4.3 vendoring（`static/vendor/README.md`）
記 katex 0.16.47 / npm 來源 / 22 項資產 SHA-256（css+js+20 woff2）/ 刷新指令 / woff2-only 理由（CSS `@font-face` woff2 首選 src、woff/ttf fallback 不取、瀏覽器用 woff2 不觸發 404；grep 證 CSS 引用 `fonts/KaTeX_Main-Regular.woff2`）。
