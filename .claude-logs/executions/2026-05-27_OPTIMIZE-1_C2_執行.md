**Step B1-B3 — upload-btn click handler 翻轉（L3193 區域）**：

舊：click → 直接建立 `<input type="file">` → POST → `showConfirmModal(paperId, suggested_doc_type, ...)`

新：
```
click
  → 重設 dropdown 預設 academic
  → modal.classList.add('show')
  → confirm-cancel-btn.onclick = () => modal.classList.remove('show')  // 零網路
  → confirm-ok-btn.onclick = () => {
      docType = dropdown.dataset.value
      modal.classList.remove('show')
      input = createElement('input')  // 動態建立 file input
      input.onchange = async (ev) => {
        FormData: file + doc_type
        POST /api/papers/upload
        → insertUploadingRow + trackProgress  // 直接追蹤 processing 狀態
      }
      input.click()
    }
```

`showConfirmModal` 函數保留（dead code，既有在途任務 UI 依賴此結構）。
