## §4 修法說明

### §4.1 `static/index.html` — `loadChatHistory` history.forEach qa-group 包裝

在 `history.forEach` 前宣告 `let currentGroup = null;`（供 in_progress 沿用），每次遇到 `msg.role === 'user'` 時建立新的 `.qa-group` div：

```javascript
let currentGroup = null;  // qa-group 容器，history.forEach + in_progress 共用（C2 RAG-14）
history.forEach(msg => {
  const div = document.createElement('div');
  if (msg.role === 'user') {
    // 每個 user message 建立新的 qa-group 容器（C2 RAG-14）
    currentGroup = document.createElement('div');
    currentGroup.className = 'qa-group';
    messages.appendChild(currentGroup);
    div.className = 'msg-user';
    div.textContent = msg.content;
  } else {
    // ... AI msg 處理（不變）
  }
  // div 掛到 currentGroup；無 group 時 fallback 直掛 messages（C2 RAG-14）
  if (currentGroup) currentGroup.appendChild(div);
  else messages.appendChild(div);
});
```

**設計考量**：若歷史首條為 AI msg（邊角情境），`currentGroup` 仍為 null，fallback `messages.appendChild` 確保不崩潰。

---

### §4.2 `static/index.html` — `loadChatHistory` in_progress currentGroup 沿用

後端協議：`history` 已含 `in_progress.query` 的 user message，`forEach` 處理後 `currentGroup` 已指向最後一個 Q&A 群組。in_progress 的 aiMsg 直接掛到 `currentGroup`：

```javascript
// in_progress aiMsg 掛到 currentGroup（與 history 內的 user msg 同組）；
// 後端已在 history 寫入 in_progress.query，不重複 render user msg（C2 RAG-14）
if (currentGroup) {
  currentGroup.appendChild(aiMsg);
} else {
  messages.appendChild(aiMsg);
}
```

**設計考量**：`else` fallback 處理無 history 但有 in_progress 的極端情況（應不存在，但防禦性保留）。

---

### §4.3 `static/index.html` — `sendMessage` qaGroup 包裝

在建立 userMsg 前先建立 `.qa-group` 容器：

```javascript
// 顯示用戶訊息（包裝在 qa-group 容器內，配合 CSS sticky 效果）（C2 RAG-14）
const messages = document.getElementById('chat-messages');
const qaGroup = document.createElement('div');
qaGroup.className = 'qa-group';
messages.appendChild(qaGroup);

const userMsg = document.createElement('div');
userMsg.className = 'msg-user';
userMsg.style.whiteSpace = 'pre-wrap';
userMsg.textContent = query;
qaGroup.appendChild(userMsg);

// 建立 AI 訊息泡泡（同組）（C2 RAG-14）
const aiMsg = document.createElement('div');
aiMsg.className = 'msg-ai';
aiMsg.textContent = '▋';
qaGroup.appendChild(aiMsg);
```
