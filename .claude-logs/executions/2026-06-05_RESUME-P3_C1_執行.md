## §4 修法說明
`pipelines/resume_pipeline.py::_build_tiles`：
```python
        tiled = output_dir / f"{paper_name}_tiled.json"
        # === [RESUME-P3 C1 START] ===
        # 履歷 opt-out TextTiling（plan v3 Q3）：直接以 JsonProcessor 的 processed JSON 作為
        # tiled（保全 ###/title/content/children heading 結構），不呼叫 TilingProcessor 向量計算。
        # → P1 不跑 TextTiling embedding：源頭消滅履歷 429（TILING-HOTFIX-1 根源）、tiles 即乾淨 heading section。
        tiled.write_text(processed.read_text(encoding="utf-8"), encoding="utf-8")
        # === [RESUME-P3 C1 END] ===
        return self._load_tiles(tiled)
```
