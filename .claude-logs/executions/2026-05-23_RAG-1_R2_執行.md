## §5 修法

### 5.1 `paper_manager.py`（+56 行）：v3 強化 `_normalize_tag` + `set_paper_tags` 整合

**新增 `_normalize_tag(tag)` module-level helper**：
- strip + `.lower()`
- 邊界：None / 非字串 / 純空白 / 全空 → 回空字串
- 中文：`.lower()` 無效、原樣保留
- 特殊字元（emoji / underscore / hyphen / 數字）：保留

**重構 `set_paper_tags`**：
- 既有 strip 邏輯改用 `_normalize_tag`
- 加 dedup（保留首次出現順序）
- R1 ship 既有 3 個 pytest 仍 passed（backward compat：純 lowercase 英文 tag 行為一致）

### 5.2 `web_server.py`（+53 行）：`upload_theme` endpoint

依 UI Plan v3 子項 B + design/theme-guide §7 規格、5 道安全過濾：
1. 副檔名限制 `.css`

3. MIME 檢查（FastAPI 內部）
4. 100KB 上限
5. 路徑強制 `static/themes/` + `resolve()` 防 traversal

放在 `/api/health` endpoint 之前、邏輯獨立。
