## §5 修法

### 5.1 `paper_manager.py` 新增 2 個 helper + `set_paper_folder` hook（+104 行）

#### `_folder_ancestor_path_names(session, owner_id, folder_id) -> list`

遞迴向 root 取 folder 從 root → leaf 的階層 name 清單：

```python
names = []
visited = set()  # 環防禦
cur_id = folder_id
max_depth = 32  # 防禦上限（既有 _folder_depth 已限 ≤ 5）
while cur_id is not None and len(names) < max_depth:
    if cur_id in visited:
        break  # 環防禦
    visited.add(cur_id)
    f = _get_folder_row(session, owner_id, cur_id)
    if f is None:
        break
    names.append(f.name)
    cur_id = f.parent_id
return list(reversed(names))  # root → leaf
```

**設計重點**：
- 用既有 `_get_folder_row` 拿 folder row（不重複實作 SQL）
- 用 `f.parent_id` 遞迴向上、reverse 後得到 root → leaf 順序
- 環防禦 + max_depth 雙保險（schema 不允許環、實務不會撞、純防禦）

#### `_apply_folder_path_tags(session, owner_id, paper_uuid, folder_id)`

- `folder_id=None` → 直接 return（移到未分類、不加自動 tag、Q7）
- 走 `_folder_ancestor_path_names` 取路徑
- 每個 name 走 R2 ship 的 `_normalize_tag`、過濾空字串
- 解析 `Paper.metadata_json`（corrupt graceful reset 為 `{}`）
- **Append + de-dup 策略**：既有 `user_tags` 不清、用 lowercase set 比對、未存在才 append
- 只有真的 append 新 tag 時才寫回 + commit（避免無用 commit）

#### `set_paper_folder` hook

在既有 commit 之後加 1 行 `try/except` 包覆呼叫：

```python
def set_paper_folder(session, owner_id, paper_uuid, folder_id):
    # ...既有檢查 + commit 100% 不動...
    p.folder_id = folder_id
    session.commit()
    logger.info(f"論文歸檔: ...")

    # RAG-1 R3：移動成功後自動加 folder 路徑 tag（不阻塞 core）
    try:
        _apply_folder_path_tags(session, owner_id, paper_uuid, folder_id)
    except Exception as e:  # pragma: no cover - 純防禦
        logger.warning(
            f"[RAG-1 R3] _apply_folder_path_tags 失敗（不阻塞 move）: {e}"
        )

    return p
```

**設計重點**：
- 既有 `set_paper_folder` 簽名 100% 不動（backward compat）
- core move 在 hook 之前已 commit、即使 hook 拋出也不影響 folder 移動
- 對齊 MODEL-8 Q12 Q13 容錯風格
