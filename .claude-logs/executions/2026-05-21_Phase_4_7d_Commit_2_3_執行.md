## Commit 3 `457f1c6` — abstract 雙語注入

### 真因

`translate_processor.translate_abstract` 在 L122-123 把翻譯後 abstract 寫進 `sections[type=='abstract'].content[].translated_content`。但 md_restore 過去**從未讀過此欄位**——`final_*_zh.md` 內 abstract 段是用「sections 一般文字塊翻譯路徑」轉出來的，靠 translate_processor.translate_content；其實能用、但抽取到 header 之後就需要 md_restore 主動取。

### 新增

- `ABSTRACT_NO_DOC_TYPES = {'news', 'web', 'slides', 'resume'}`（與 translate_processor 對齊 + 含 resume；含 doc_type-registry marker）
- `_resolve_abstract(data, doc_type)` → `(en, zh, log)`
  - 從 `sections` 找 `type == 'abstract'`
  - 取第一個 `type == 'text'` 的 content item
  - 英文取 `content`；中文取 `translated_content`
  - 中文空 → fallback 英文（避免中文版完全缺）
  - doc_type 屬 NO_TYPES → 直接空
- `_render_header_en / _render_header_zh` 簽名加 `abstract: str = ''`
  - 有 abstract → 追加 `## Abstract` / `## 摘要` block
  - resume header 忽略 abstract 參數

### process() 整合

- 呼叫 `_resolve_abstract`
- header_en/zh 接 `abstract=...`
- `self._abstract_consumed = bool(abstract_en or abstract_zh)`
- 主 sections 迴圈：若 `_abstract_consumed and section.type=='abstract'` → skip（避免重複寫）

### 8 新測試

- `_resolve_abstract` 5（found / fallback / news skip / resume skip / no section）
- `_render_header_*_with_abstract` 2
- `_render_header_resume_no_abstract_block` 1
