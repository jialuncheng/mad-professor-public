## §5 修法 + 測試結果

### 修法（核心）
- `index(sections, section_summaries, doc_type, vectors_dir, paper_db_id=None, size_cap_tokens)`：
  1. `build_chunk_markdown`（C3）→ 串為 full_md。
  2. `MarkdownHeaderTextSplitter([("#","Header")])` 切（與 A 軌建立端 / `rag_retriever` 讀取端對齊）。
  3. 自實作 `is_chunk_meaningful` 過濾（安全網）。
  4. **`EmbeddingModel.get_instance()` + `FAISS.from_documents(distance_strategy=MAX_INNER_PRODUCT)` → `save_local`**（embedding 於 DB 交易外）。
  5. `paper_manager.replace_paper_chunks(paper_db_id, rows)`（rows 欄位對齊 `models.PaperChunk`；`paper_db_id=None` → 降級跳過）。
  6. `_write_index_meta`（自寫 `index_meta.json`、簽章 embedding_model/output_dimensions/chunk_filter_version 與 A 軌相容）。
  7. 交付 `RagDbSpec(vectors_path, paper_chunk_count, index_meta)`。
- **零 import rag_processor**：`write_index_meta_json` / `_is_chunk_meaningful` / `CHUNK_FILTER_VERSION` 皆自實作等價。
