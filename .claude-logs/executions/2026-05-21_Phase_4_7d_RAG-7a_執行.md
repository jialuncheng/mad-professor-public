## 修法

### 1. `settings.py` 加常數

```python
# Phase 4.7d RAG-7a：浮水印偵測閾值
# 整篇 markdown 內出現 ≥ N 次的 heading line 視為浮水印、整行移除
# 預設 3（DeHunt 履歷實測 XDeHunt 出現 5 處、HDeHunt 出現 5 處）
WATERMARK_HEADING_THRESHOLD = int(os.getenv("WATERMARK_HEADING_THRESHOLD", "3"))
```

### 2. `processor/md_cleaner.py` 加偵測 + 清理

新 `@staticmethod _detect_watermark_headings(lines, threshold=3) -> set`：
- 統計每行 strip 後若以 `#` 開頭、normalize（`lstrip('#').strip().casefold()`）後計數
- 回傳 `{normalized_text}` set、計數 ≥ threshold

`clean()` 內擴 Step 2（既有 Step 1 圖表純數字行清理保留不動）：
- 對 Step 1 後的 lines 跑 `_detect_watermark_headings`
- 若有浮水印 → 第二輪掃描 lines、移除所有 heading 行其 normalize 字串在 watermarks set 內
- log 每個浮水印的移除次數：`[md_cleaner] 移除浮水印 heading: 'xdehunt' (5 次)`

### 3. tests/test_md_cleaner.py（新檔，121 行）

6 個測試覆蓋 plan §6.2：

| # | 測試 | 驗證 |
|---|---|---|
| 1 | `test_existing_numeric_line_removed` | 既有圖表純數字行邏輯回歸驗證 |
| 2 | `test_watermark_heading_removed_threshold_3` | 3 次 `# XDeHunt` 全移除；1 / 2 次 heading 保留 |
| 3 | `test_watermark_case_insensitive` | `XDeHunt` / `xdehunt` / `XDEHUNT` 算同一個 |
| 4 | `test_watermark_different_hash_count_same` | `# X` / `## X` / `### X` normalize 後算同一個 |
| 5 | `test_normal_heading_not_removed` | 履歷正常 heading（Working Experience / VIEWTRIX / MIT）單次保留 |
| 6 | `test_threshold_env_override` | env `WATERMARK_HEADING_THRESHOLD=2` 重 reload settings 後生效 |
