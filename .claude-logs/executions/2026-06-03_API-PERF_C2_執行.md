## §4 修法說明

### §4.1 `web_server.py` `upload_paper` — U4 1MB 分塊流式寫入（`=== [API-PERF C2 START/END] ===`）
取代原 `content = await file.read()`（一次性入 RAM）→ 先定 `paper_id`/`paper_dir`/`pdf_path`，再 `while chunk := await file.read(1MB)` 邊讀邊寫磁碟；首塊校驗 `chunk[:4]==b'%PDF'`（否則 `_reject=(415,...)` break）；`_total>100MB` 截斷（`_reject=(413,...)` break）；空檔（無 chunk）視 415；失敗 `pdf_path.unlink(missing_ok=True)` 清理 partial 檔後回 JSONResponse。

```python
_CHUNK_SIZE = 1024 * 1024; _MAX_SIZE = 100*1024*1024
_total = 0; _first = True; _reject = None
with open(pdf_path, 'wb') as f:
    while True:
        chunk = await file.read(_CHUNK_SIZE)
        if not chunk: break
        if _first:
            _first = False
            if chunk[:4] != b'%PDF': _reject = (415, "僅支援 PDF 格式"); break
        _total += len(chunk)
        if _total > _MAX_SIZE: _reject = (413, "檔案大小超過 100 MB 上限"); break
        f.write(chunk)
if _first and _reject is None: _reject = (415, "僅支援 PDF 格式")
if _reject is not None:
    pdf_path.unlink(missing_ok=True); return JSONResponse(status_code=_reject[0], content={"error": _reject[1]})
```

### §4.2 `web_server.py` `login` — U5 真實 IP（`=== [API-PERF C2 START/END] ===`）
```python
_xff = request.headers.get("X-Forwarded-For")
if _xff:
    ip = _xff.split(",")[0].strip() or "unknown"   # 最左真實 client IP
else:
    ip = request.client.host if request.client else "unknown"
```
