## §4 修法說明

### §4.1 Change A — `setThemes()` 方法加入 `dropdownAPI` 回傳物件

在 `dropdownAPI` IIFE 的回傳物件 `getThemeLabel(name)` 之後插入 `setThemes(themesList)` 方法：

```javascript
setThemes(themesList) {
  // RAG-13：動態覆寫選單資料（清空 + 重建 THEMES 陣列與 themeLabels map）
  THEMES.length = 0;
  for (const k in themeLabels) delete themeLabels[k];
  themesList.forEach(t => {
    THEMES.push([t.name, t.label]);
    themeLabels[t.name] = t.label;
  });
},
```

**設計決策**：`THEMES.length = 0` 清空陣列而不替換引用，確保 `setupOne` IIFE 時已捕捉到的 `THEMES` closure 引用仍有效。

### §4.2 Change B — `setupOne` 分隔線邏輯

在 `items.forEach(([val, label]) => {` 前加 `let hasCustomHeader = false;`，並在 forEach 第一行插入 guard：

```javascript
let hasCustomHeader = false;
items.forEach(([val, label]) => {
  if (dd.id === 'theme-dropdown' && !['mies', 'kahn', 'kandinsky', 'nara'].includes(val) && !hasCustomHeader) {
```

**設計決策**：`dd.id === 'theme-dropdown'` guard 防止其他 dropdown（doc-type）插入分隔線；`--color-divider, var(--color-border)` fallback 確保跨主題相容。

### §4.3 Change C — `loadThemesFromServer()` 函式宣告與初始化呼叫

在 `if (savedTheme) { ... }` 區塊結尾之後插入：

```javascript
// ─── RAG-13：動態讀取自訂主題清單並渲染 ───
async function loadThemesFromServer() {
  try {
    const res = await fetch('/api/themes');
    if (!res.ok) throw new Error('Failed to fetch themes');
    const themesList = await res.json();

    const builtInOrder = ['mies', 'kahn', 'kandinsky', 'nara'];
    const builtInThemes = themesList.filter(t => !t.custom)
      .sort((a, b) => builtInOrder.indexOf(a.name) - builtInOrder.indexOf(b.name));
    const customThemes = themesList.filter(t => t.custom)
      .sort((a, b) => b.updated_at - a.updated_at);

    const sortedThemes = [...builtInThemes, ...customThemes];
    dropdownAPI.setThemes(sortedThemes);

    const currentTheme = localStorage.getItem(THEME_KEY) || 'kahn';
    const dd = document.getElementById('theme-dropdown');
    dd.dataset.value = currentTheme;
    dd.querySelector('.dropdown-value').textContent = dropdownAPI.getThemeLabel(currentTheme);
  } catch (err) {
    console.error('[Theme Load Error]', err);
  }
}

loadThemesFromServer();
```

**設計決策**：`loadThemesFromServer()` 無 `await` 呼叫（fire-and-forget），不阻塞頁面初始化；`if (savedTheme)` 同步 fallback 仍保留，確保 fetch 完成前 dropdown 即時顯示。

### §4.4 Change D — upload handler 改呼叫 `await loadThemesFromServer()`

將 upload handler 中的舊 5 行區塊：

```javascript
// BUG-F2 A5：動態追加進 THEMES、dropdown 重渲染時可見、跨重整不失效
dropdownAPI.addTheme(themeName);
// 更新 dropdown 顯示
const dd = document.getElementById('theme-dropdown');
dd.dataset.value = themeName;
dd.querySelector('.dropdown-value').textContent = dropdownAPI.getThemeLabel(themeName);
```

替換為：

```javascript
// RAG-13：重新從伺服器讀取最新主題清單（含新上傳的自訂主題）
await loadThemesFromServer();
```

**設計決策**：`await` 在 `async (e) => {}` handler 內合法；`loadThemesFromServer()` 統一處理選單重建 + dropdown 顯示更新，消除重複邏輯。
