## §5 修法

對應 plan §3.1 + §3.6：

### 5.1 `models.py` — 加 `PaperChunk` class + `Paper.chunks` relationship

關鍵變動：
- `Paper` 既有欄位 / relationships 100% 不動、只在 `conversations` relationship 之後加 1 個 `chunks` relationship（`cascade="all, delete-orphan"` + `passive_deletes=True` + `order_by="PaperChunk.chunk_index"`）
- 末尾新增 `class PaperChunk(Base)`、欄位：
  - `id` (PK) / `paper_id` (FK papers.id ON DELETE CASCADE)
  - `chunk_index` (INT、序鍵) / `chunk_key` (str, 255、語意鍵)
  - `raw_text` (Text, 非空) / `translated_text` (Text, 可空、暫不填)
  - `doc_type` / `metadata_json` (JSON 字串)
  - `embedding_model` (str, 100、非空) / `output_dimensions` (INT, 非空)
  - `chunk_filter_version` (str, 50、可空)
  - `created_at` (DateTime、server_default func.now())
- 索引：`ix_paper_chunks_paper_id` / `ix_paper_chunks_embedding_model` + UNIQUE `(paper_id, chunk_index)`
- **修正 3**：無 `tiling_method` 欄位

### 5.2 `paper_manager.py` — 加 3 個 DAL helper

- `replace_paper_chunks(paper_db_id, chunks: list[dict]) -> int`：覆寫式批次 INSERT、用 SQLAlchemy 2.0 `insert(PaperChunk)` 批量、< 50ms/千筆（db_analysis §4 效能要求）
- `iter_paper_chunks(paper_db_id)`：yield dict、依 `chunk_index` 升序
- `list_papers_with_chunks(owner_id=None) -> list[dict]`：JOIN `papers + paper_chunks`、回 distinct `paper × embedding model`、供 C3 `regen_rag --check` 用
- **import 擴充**：`from models import ... PaperChunk`
- **不重做** `get_paper_db_id`（修正 5、L336-343 已存在）

### 5.3 `processor/rag_processor.py` — 加 `CHUNK_FILTER_VERSION` 常數

- module-level：`CHUNK_FILTER_VERSION = 'B2-2026-05-22'`
- 對應 MODEL-1+2 B2 `_is_chunk_meaningful` 過濾邏輯（L35-81）邏輯版本錨點
