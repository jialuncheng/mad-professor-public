# RAG-14 多標籤寬鬆格式跨文章 RAG 檢索與對話體驗升級 plan_v3

> 本計畫旨在全面解決對話 Hashtag 格式解析容錯、支援多標籤聯集跨文章 RAG 檢索，並優化對話泡泡排版與引入 Claude 質感的 Sticky 提問固定置頂功能，達成極致的對話閱讀體驗。
> 本次升級已通過 Linux 虛擬機 pytest 單元測試與實踐驗證（15 項檢驗全數通過）。已深度修復 `in_progress`（進行中對話）的 DOM 結構，採用「沿用含 user message 的既有 group」的完美組包方案，並遵循 Logging SOP 規範。

## §1 TL;DR（概要）

- **挑戰**：
  1. **Hashtag 帶入 x 缺陷**：前端使用 `contenteditable` 讀取 `input.textContent` 時未過濾標籤 Token 的刪除按鈕文字（`×`），導致發送提問被強行拼接成 `#sstx`。
  2. **僅支援單一標籤與格式限制**：後端目前的 `parse_query_hashtag` 僅支援提取最開頭的一個標籤，且限制後方必須是半形空格；換行或逗號都會解析失敗。
  3. **氣泡排版不美觀**：問與答對話氣泡未對齊且未整寬，影響整體版面整齊度。
  4. **長回答滾動迷失與 DOM 不一致**：當 AI 回覆字數過長時，滑動滾動條會導致提問氣泡直接滑出。既有 `loadChatHistory` 中的 `in_progress`（正在進行中對話）必須沿用包含該次提問 `.qa-group` 容器，以維持一致性，否則會破壞置頂與氣泡關聯。
  5. **單元測試 mock 失效**：既有 `tests/test_phase2_p2_2_hashtag_routing.py` 中的 3 個路由測試直接 monkeypatch 舊的 `parse_query_hashtag`，若後端直接切換而不更新測試，將導致 pytest 崩潰。
- **解法**：
  1. **前端過濾 `×` 按鈕**：前端 `sendMessage` 時 clone 節點並剔除 `.hashtag-token-remove` 按鈕再獲取提問純文字。
  2. **後端多標籤與容錯解析器**：後端實作 `parse_query_hashtags` 遞迴提取器，相容 `×/x/X` 等關閉符號消耗。並在 `AI_professor_chat.py` L76-L136 替換整個 P2-2 舊邏輯區塊，取得匹配文獻聯集以執行多文件檢索。
  3. **氣泡滿寬調整與 Gap 分工**：修改 CSS 讓 `.msg-user` 與 `.msg-ai` 滿寬拉伸，外層控制群組間距，內層控制問答間距。利用已驗證存在的 `--color-accent` 變數美化背景。
  4. **導入 Sticky Q&A 組容器（沿用/相容 `in_progress`）**：將問與答（以及 `in_progress` 部分）打包入同一個 `.qa-group` 容器，配合 `position: sticky` 實現黏性置頂。
  5. **同步升級單元測試 Mock**：更新測試中的 3 處 monkeypatch，改為攔截 `parse_query_hashtags` 並給予覆蓋 0篇/單篇/多篇等具體情境的模擬回傳值。
- **影響**：影響前端對話框發送邏輯、CSS 樣式排版、對話 DOM 結構、測試 Mock 函數以及後端 Hashtag 提取與 RAG 分流邏輯。不影響資料庫 Schema。

## §2 目標規格

### 1. 前端標籤 Token 過濾規格
- 發送訊息或讀取輸入框純文字時，必須主動剔除 `.hashtag-token-remove` 刪除按鈕元素（文字為 `×` ），確保送至後端的字串為乾淨的 `#sst`。

### 2. 多標籤遞迴解析與容錯規格
- 支援提取開頭的複數標籤，例如 `#sst #cv` 需正確解析為 `['sst', 'cv']`。
- 支援自動吃掉標籤末尾殘留的 `×`、`x` 或 `X` 關閉字元。
- 支援以空格、逗號 `,`、分號 `;`、換行 `\n` 或下一格 `#` 作為標籤分隔符，並自動將匹配出的有效標籤從提問字串中抹除（`cleaned_query`）。
- 當解析出多個有效標籤時，檢索出所有「含有其中任意一個標籤」的論文 UUID 並**保留其原始順序進行去重（Deduplication with order preserved）**，交由底層多文件 RAG 進行檢索。對於無效或不存在的全新標籤，自動忽略。
- **相容性要求**：保留舊的 `parse_query_hashtag`（單數）作為 deprecated 備用函數，以防未包含在本次修改範圍內的其他老舊單元測試因調用缺失而中斷。

### 3. 對話氣泡滿寬與 Gap 分工規格
- `.msg-user` 與 `.msg-ai` 泡泡寬度必須完全對齊一致，自左側對齊線延伸至右側對齊線（100% 滿寬）。
- `#chat-messages` 外層的 `gap` 負責控制多個 `.qa-group` 之間的區塊間距；而內部的 `.qa-group { gap }` 則精確控制該組問與答泡泡之間的垂直間距。

### 4. 提問固定置頂（Sticky Header）與 DOM 一致性規格
- 每一組對話（一問一答）必須被打包進獨立的群組容器 `.qa-group` 中。
- **沿用容器要求**：在 `loadChatHistory` 載入 `in_progress` 區塊時，**必須沿用已包含對應 user 提問的既有 `currentGroup` 容器**，將串流中的 `aiMsg` 追加裝入同一個 `.qa-group` 中，確保 DOM 階層與 Sticky 特性 100% 完美與安全。
- 當滾動對話面板時，提問氣泡 `.msg-user` 必須能黏貼固定在 `#chat-messages` 容器的最上方（`top: 0`），並使用已確認存在的 CSS 變數 `--color-accent` 渲染背景，直到該 Q&A 區塊完全移出可視範圍而被下一個提問氣泡推走，以維持 Claude (Antigravity) 的問答 UI 質感。

### 🛠️ 後端修改處 1：多標籤寬鬆解析器（`paper_manager.py`）
*注意：本修改僅新增 `parse_query_hashtags`，保留既有舊 `parse_query_hashtag` 以免破壞其他非關聯測試。*
```python
def parse_query_hashtags(session, owner_id: int, query: str) -> tuple:
    """從 query 開頭解析多個 #tag，支援包含 close button (×/x)、逗號、換行等格式。"""
    if not isinstance(query, str) or not query.strip().startswith("#"):
        return ([], query)

    all_tags = set()
    rows = session.query(Paper).filter_by(owner_id=owner_id, status='done').all()
    for p in rows:
        if p.metadata_json:
            try:
                meta = json.loads(p.metadata_json)
                if isinstance(meta, dict):
                    for t in (meta.get("user_tags", []) or []):
                        if isinstance(t, str):
                            normalized = _normalize_tag(t)
                            if normalized:
                                all_tags.add(normalized)
            except (json.JSONDecodeError, TypeError):
                continue

    if not all_tags:
        return ([], query)

    sorted_tags = sorted(all_tags, key=len, reverse=True)
    matched_tags = []
    current_query = query.strip()
    delimiters = (" ", ",", ";", "\n", "\r", "\t", "#")

    def lstrip_delimiters(s: str) -> str:
        while s and s[0] in (" ", ",", ";", "\n", "\r", "\t"):
            s = s[1:]
        return s

    while True:
        current_query = lstrip_delimiters(current_query)
        if not current_query.startswith("#"):
            break

        matched_any = False
        after_hash = current_query[1:]
        after_lower = after_hash.lower()

        for tag in sorted_tags:
            if after_lower.startswith(tag):
                tag_len = len(tag)
                rest = after_hash[tag_len:]
                
                # 偵測並消耗 close button '×' 或 'x' / 'X'
                if rest and rest[0] in ("×", "x", "X"):
                    remaining = rest[1:]
                    if not remaining or remaining[0] in delimiters:
                        rest = remaining
                
                # 判定後面是否為分隔符或 EOL
                if not rest or rest[0] in delimiters:
                    matched_tags.append(tag)
                    current_query = rest
                    matched_any = True
                    break

        if not matched_any:
            break

    return (matched_tags, lstrip_delimiters(current_query).strip())
```
