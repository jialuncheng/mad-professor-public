## §5 修法

### 5.1 `web_server.py` 加 trace_id middleware（依 §4.4 + §4.11）

**插入位置**（grep 結果 + Starlette stack 推理）：

Starlette `add_middleware` 是 LIFO stack：last-added = outermost（先執行）。grep 證實既有順序：

| 行號 | 動作 | 對應 stack 狀態（outer→inner） |
|---|---|---|
| L228 | `add_middleware(CORS)` | [CORS] |
| L260 | `@app.middleware("http")` 加 `auth_guard` | [auth_guard, CORS] |
| **新增 L271** | `@app.middleware("http")` 加 `trace_id_middleware` | [trace_id, auth_guard, CORS] |
| L323（原 L271 推移） | `add_middleware(SessionMiddleware, ...)` | [Session, trace_id, auth_guard, CORS] |

執行順序：**Session → trace_id → auth_guard → CORS → handler**。

關鍵：trace_id_middleware 在 SessionMiddleware **之內**、所以 `request.session` 已被注入、可讀 `session.get("user")` 取 owner ✅。

**middleware 函式**：

```python
import uuid as _uuid
from utils.logging_config import trace_context as _trace_context


@app.middleware("http")
async def trace_id_middleware(request: Request, call_next):
    incoming = request.headers.get("X-Trace-ID")
    trace_id = incoming if incoming else _uuid.uuid4().hex[:8]

    owner = None
    try:
        if hasattr(request, "session"):
            owner = request.session.get("user")
    except Exception:
        owner = None

    token = _trace_context.set({
        "trace_id": trace_id,
        "owner": owner,
        "path": request.url.path,
        "method": request.method,
    })
    try:
        response = await call_next(request)
    finally:
        _trace_context.reset(token)

    response.headers["X-Trace-ID"] = trace_id
    return response
```

**設計要點**：
- 用底線前綴 `_uuid` / `_trace_context` 避免污染 web_server 全域命名空間（與既有 `import uuid` / `trace_context` 衝突風險為 0）
- `hasattr(request, "session")` + `try/except` 雙保險：若未來 SessionMiddleware 設定變動、本 middleware 仍能跑（owner=None）
- `try/finally` 包覆 `call_next` + `_trace_context.reset(token)`：即使內層 raise、ContextVar 必 reset
- `response.headers["X-Trace-ID"] = trace_id` 寫回：前端可在 fetch options 內 `headers: { 'X-Trace-ID': prevId }` 串連多次 API call

**owner key 命名**：grep 證實 session 用 `session["user"]`（username 字串、L317 / L355）、本 middleware 同步使用、ContextVar 內欄位名為 `"owner"`（語意一致：是「使用者」、不是 user_id INT PK）。
