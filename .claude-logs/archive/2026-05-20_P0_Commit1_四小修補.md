## 改動 1：B-1 textarea 送出後自動縮回

**真因**：sendMessage 程式設值 `input.value = ''` 不會觸發 `input` 事件
→ prototype `ta` listener 不執行 → textarea 高度卡住。

**修法**（+1 行）：
```diff
   input.value = '';
+  input.dispatchEvent(new Event('input'));  // 觸發 prototype ta listener 重算高度
   isStreaming = true;
```
- 沿用 prototype 為單一真源、不依賴其 listener 邏輯細節
- 不會無限迴圈：prototype `ta` listener 只操作 `style.height`，
  programmatic style 修改**不**觸發 `input` event；事件僅由 user input
  或 `dispatchEvent` 主動觸發 → 單次重算後即停。

## 改動 4：C-3 列印時隱藏 `.ctx-popup`（+1 selector）

**真因**：既有 `@media print` 隱藏清單已含 `#sidebar / #chat-panel /
#content-toolbar / #empty-state / #tooltip / .modal-mask`，但**漏 `.ctx-popup`**
（動態建立的論文/資料夾 ⋯ popup 與 dropdown 列表）。

**修法**（既有規則內 +1 selector）：
```diff
     #tooltip,
-    .modal-mask {
+    .modal-mask,
+    .ctx-popup {
       display: none !important;
     }
```
- `#tooltip` / `.modal-mask` 既存於規則內（前輪列印 CSS 已加），本次僅補
  `.ctx-popup`
