## Edge case 發現
1. **空 title vs 雜訊 title**：fitz title 為空字串 → `None`；
   `Microsoft Word - draft.docx`/`Untitled` 等 → 判定雜訊 `None`（不污染 Stage A）。
   raw 雜訊值目前不寫入 alternates（_clean_title 在 extract 階段已濾除）；
   若未來仲裁需要看原始雜訊值，可於 Phase 4.4 再決定是否保留。
2. **creationDate ≠ 發表日**：`publication_date` 由 creationDate 帶入但
   confidence=medium，符合 Phase 4.1「製檔日非發表日」設計；LLM 第一頁（Phase 4.3）
   抽到明確發表日時應優先。
3. **organization**：PDF metadata 無此欄，恆 None（交由 Phase 4.3 LLM 判斷）。
4. **日期非法**：`D:20259999`（月份非法）→ None（不臆造）。
5. **損壞/不存在 PDF**：三個抽取函式均 soft fail（None/[]），fill 也不 raise。
6. 環境註記：`.DS_Store` 在 git status 顯示為 M，屬既有被追蹤的 macOS 垃圾檔、
   非本任務變更，未觸碰、未提交。
