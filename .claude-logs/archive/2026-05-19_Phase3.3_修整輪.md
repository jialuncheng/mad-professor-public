## 第一部分：明確修正

- **A1 三階間距 token**：:root 新增 `--gap-btn-tight: var(--space-1)`(4)、
  `--gap-btn`(8)、`--gap-btn-loose: var(--space-3)`(12)。
- **A2 選中統一**：`.paper-item.active`、`.btn-ghost.active` 由 `var(--color-accent)`
  改 `var(--color-text)`（white 字）。`.folder-item.active` 原已 `var(--color-text)`。
  grep 確認全站 `.active` 無再用 color-accent。「未分類灰底」：JS/CSS 無此專屬規則
  （fixed 節點與一般 folder-item 同 class、選中走同一 .active），原感知應為 hover
  （`.folder-item:hover` 灰底，全列一致），無差異需移除——已查證並標註。
- **I1 中欄改 icon-only**：`#lang-toggle`（左右切換弧箭頭 SVG）、`#print-btn`
  （印表機 SVG）改 `class="icon-only"` 32×32。**連帶必要修正**：原 lang-toggle
  onclick 以 `textContent` 切換標籤會覆蓋 SVG → 改為更新 `title`（語言切換行為不變，
  仍 fetchContent）。已標註此 JS 微調（行為等價）。
- **I2 標題列重佈局**：`#sidebar h1` padding 由左 44 改右 44（讓位浮動漢堡）、
  gap → loose、`.title` flex:1 ellipsis；`#sidebar-toggle` `left:216px`
  （≈260−12−32，視覺貼齊標題列右端）。**保留 position:fixed**：評估後最小破壞
  方案——若移入 #sidebar 流內，collapsed(width:0;overflow:hidden) 會使漢堡消失
  而無法再展開（fixed 不受祖先 overflow 裁切，故 collapsed 時仍可點再展開；
  代價：collapsed 時漢堡浮於內容區左側，可接受）。順序＝標題(左,可省略)→
  new-folder→漢堡(最右浮動)。
- **I3 底部三鈕等寬**：`#sidebar-bottom .sb-row` gap → tight；新增
  `.sb-row > button { flex:1; min-width:0; width:auto }` 覆寫 .icon-only 固定寬，
  三鈕等寬平分＝upload 寬，高 32、icon 置中（沿用 ghost inline-flex center），icon 保留。
- **I4 標題格式**：`.title` 保持 ellipsis（標題為靜態「文件列表」短字、不會溢出）；
  h1 維持固定 `var(--toolbar-h)`。**spec 內部衝突**：I4 要「過長換行 head 變高」
  又要「維持 toolbar 高度」——二者互斥；因標題靜態短字，採 G3 固定高一致性，
  wrap/變高在此無實際觸發。已標註取捨。
- **I5 右欄/標題列間距**：`#chat-header`、`#chat-header-actions`、`#content-toolbar`
  gap 統一 `var(--gap-btn-loose)`；`#sidebar h1` gap 亦 loose（標題列家族一致）。
