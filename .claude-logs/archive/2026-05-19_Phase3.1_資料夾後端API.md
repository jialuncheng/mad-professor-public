## 新增端點（web_server，皆 Depends(get_current_user) + owner 範圍）
- `GET    /api/folders`              → flat list（前端建樹）
- `POST   /api/folders`              {name, parent_id?} → 建立；失敗 400
- `PATCH  /api/folders/{folder_id}`  {name?, parent_id?, sort_order?}；不存在 404、驗證 400
- `DELETE /api/folders/{folder_id}`  → {deleted_folders:N}；不存在 404
- `PATCH  /api/papers/{paper_uuid}`  {folder_id}（None=未分類）；論文不存在 404、目標資料夾不存在 400
- `GET /api/papers`：URL 不變，dict 已含 `folder_id`（透過 _to_dict，前端 Phase 3.2 用）

## nullable PATCH 解法：採 **A（model_fields_set）**
Pydantic v2 `req.model_fields_set` 判斷欄位是否「有提供」：
- 未提供 → 不改（parent_id 傳 `paper_manager.UNSET` sentinel；name/sort_order 傳 None＝不改）
- 提供 null → 設為 NULL（parent_id=None 移到根；paper folder_id=None 移到未分類）
- 三欄皆未提供 → 400「未提供任何可更新欄位」；paper 未提供 folder_id → 400

## 錯誤處理
- 400：名稱長度、深度超限、同層同名、上層不存在、移到子孫（防環）、未提供欄位
- 404：folder/paper 不存在
- 跨 owner：get_folder/paper_exists 以 owner 過濾 → 回 404（**刻意採 404 而非 spec 的 401**：
  不洩漏資源是否存在、避免 enumeration，安全性較佳；已於此標註此一偏離與理由）
- 訊息為中文、可直接顯示給使用者

## F. curl 測試說明（正式環境，需先登入取 cookie）
```bash
# 1. 登入（帳號/密碼依 .env 的 AUTH_USERNAME 與你設定的密碼）
curl -i -X POST http://localhost:8080/login \
  --data-urlencode "username=$AUTH_USERNAME" \
  --data-urlencode "password=你的密碼" \
  -c /tmp/ck.txt              # 成功為 303，cookie 存 /tmp/ck.txt

# 2. 列資料夾（初次為 []）
curl -s -b /tmp/ck.txt http://localhost:8080/api/folders

# 3. 建資料夾（root / 子）
curl -s -b /tmp/ck.txt -H 'Content-Type: application/json' \
  -d '{"name":"研究論文"}' http://localhost:8080/api/folders
curl -s -b /tmp/ck.txt -H 'Content-Type: application/json' \
  -d '{"name":"LLM","parent_id":1}' http://localhost:8080/api/folders

# 4. 改名 / 移動 / 排序（未提供的欄位不變）
curl -s -X PATCH -b /tmp/ck.txt -H 'Content-Type: application/json' \
  -d '{"name":"重要論文"}' http://localhost:8080/api/folders/1
curl -s -X PATCH -b /tmp/ck.txt -H 'Content-Type: application/json' \
  -d '{"parent_id":null}' http://localhost:8080/api/folders/2   # 移到根

# 5. 論文歸檔 / 移回未分類
curl -s -X PATCH -b /tmp/ck.txt -H 'Content-Type: application/json' \
  -d '{"folder_id":1}' http://localhost:8080/api/papers/kahneman2009
curl -s -X PATCH -b /tmp/ck.txt -H 'Content-Type: application/json' \
  -d '{"folder_id":null}' http://localhost:8080/api/papers/kahneman2009

# 6. 刪資料夾（子資料夾連帶刪、論文 folder_id 設 NULL）
curl -s -X DELETE -b /tmp/ck.txt http://localhost:8080/api/folders/1

# 7. 論文清單已含 folder_id
curl -s -b /tmp/ck.txt http://localhost:8080/api/papers | head
```
注意：`/login` 路徑為 `/login`（非 `/api/login`）；密碼需與 `.env` 之 `AUTH_PASSWORD_HASH`
（由 scripts/generate_password_hash.py 產生）相符。
