## 阻斷性問題與真因

### 1. 阻斷現象 (Block Issue)
- **現象描述**：當對話面版向下滾動時，已滾動上去的白色舊 AI 訊息氣泡（來自上一個 `.qa-group`），在已置頂黏貼的黑色用戶訊息氣泡 `.msg-user` 的上方（對齊邊界）穿透顯露出來，破壞了 Claude 質感置頂與排版的視覺完整度。
- **受災範圍**：前端 AI 問答對話面板面滾動效果與置頂排版視覺。
- **現象截圖**：`media__1780051054343.png`

### 2. 真因診斷 (Root Cause)
- **技術細節**：
  1. 滾動容器 `#chat-messages` 具有頂部內邊距 `padding-top: var(--space-5)` (約 20px / 24px)。
  2. 當 `.msg-user` 設定 `position: sticky; top: 0` 時，它是黏貼在滾動內容區域（content-box）的 `top: 0` 位置。
  3. 這導致在滾動內容區域上方，存在著一個高度為 `var(--space-5)` 的**透明 padding-top 區域**。
  4. 當舊訊息向上滾動時，會越過 content-box 的 `top: 0` 邊界進入這個 transparent 區域。由於 `.msg-user` 黑色氣泡只貼在 `top: 0` 處，無法遮蔽 padding 區，舊訊息就在其上方穿透漏出。

- **定位程式碼**：[static/index.html L912](file:///Users/baroncheng/OrbStack/claude-lab/home/baroncheng/mad-professor-public/.claude/worktrees/hopeful-yalow-902c50/static/index.html#L912) & [L931](file:///Users/baroncheng/OrbStack/claude-lab/home/baroncheng/mad-professor-public/.claude/worktrees/hopeful-yalow-902c50/static/index.html#L931)

## 熱修復修法 (Minimal Hotfix - 決策：採納方案 B)

經 baron 與 AI 設計評估，本緊急修復決定採納**【方案 B】**，從根本上消除透明內邊距通道。方案 A 做為備選比較方案記錄存檔。

### 🟢 採納方案 B：移出頂部 Padding 改用 Margin 留白（語意純粹、100% 裁切邊界重合）

將滾動容器頂部的 `padding-top` 設為 `0`，改用第一個 QA 組的 `margin-top` 補回留白，確保置頂邊界與裁切邊界完全重合，從根本上消除透明穿透帶。

#### [static/index.html](file:///Users/baroncheng/OrbStack/claude-lab/home/baroncheng/mad-professor-public/.claude/worktrees/hopeful-yalow-902c50/static/index.html#L912) — 實體改動
```diff
  #chat-messages {
    flex: 1;
    overflow-y: auto;
    scrollbar-gutter: stable;                                     /* 永遠保留捲軸位、左右視覺對稱 */
-   padding: var(--space-5) var(--chat-pad-x, var(--space-5));    /* 與 input-area 共用水平 padding，邊界對齊 */
+   padding: 0 var(--chat-pad-x, var(--space-5)) var(--space-5);  /* 頂部設為 0，防置頂穿透（RAG-14）*/
    display: flex; flex-direction: column;
    gap: var(--space-6);                                             /* qa-group 外部間距（C1 RAG-14）*/
  }
  
  .qa-group {
    display: flex; flex-direction: column;
    gap: var(--space-4);                                             /* user/ai 內部間距（C1 RAG-14）*/
  }
+ .qa-group:first-child {
+   margin-top: var(--space-5);                                      /* 首個 QA 組補回頂部留白（RAG-14）*/
+ }
```

### 🟡 備選方案 A：調整 Sticky 置頂高度抵消 Padding（置頂黏貼位移）

將 `.msg-user` 的置頂定位由 `top: 0;` 修改為**負的頂部 Padding 值**，使其在滾動黏貼時向上拉伸，完美遮擋頂部透明 padding 區域：

#### 備選代碼
```css
  .msg-user {
    /* ... 既有樣式 ... */
    position: sticky;                                                /* Q&A sticky header（C1 RAG-14）*/
    top: calc(-1 * var(--space-5));                                  /* 抵消容器 padding-top，防滾動內容穿透（RAG-14）*/
    z-index: 10;
    box-shadow: 0 2px 8px rgba(0,0,0,0.05);
  }
```
